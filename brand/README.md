# Candor — Brand Assets

Логотип продукту **Candor** (privacy proof-of-solvency на Midnight). Пакет для розробників: вектор (SVG — джерело правди) + растр (PNG у розмірах).

## Концепт
Знак — **діафрагма обʼєктива**: впускає рівно стільки, скільки дозволено. Пряма метафора *selective disclosure* — «доводимо факт, розкриваємо контрольовано». Шестигранний отвір — субтильний кивок на ZK.

## Кольори
| Роль | HEX |
|---|---|
| Gold (знак, акцент, «C») | `#C79A4E` |
| Wordmark на темному | `#F1F5F9` |
| Wordmark на світлому | `#0F172A` |
| Tagline / muted | `#94A3B8` |
| App-icon фон (navy) | `#0B0F1C` |

## Який файл коли
| Файл | Використання |
|---|---|
| `candor-primary-dark` | горизонтальний lockup **на темному** фоні |
| `candor-primary-light` | горизонтальний lockup **на світлому** фоні |
| `candor-stacked-dark/light` | вертикальний lockup (вузькі місця) |
| `candor-wordmark-dark/light` | тільки слово, без знака |
| `candor-icon` | тільки діафрагма (прозорий фон) — вбудовувати будь-де |
| `candor-app-icon` | іконка застосунку / Discord-аватар (має власний navy-фон, rounded) |
| `candor-favicon` | вкладка браузера (потовщені лінії, без тонкого кільця — читається на 16px) |
| `candor-mono-gold/black/white` | одноколірний друк / штамп / knockout |

- SVG: `svg/*.svg` — масштабуються без втрат, редаговані.
- PNG: `png/*-{ширина}.png` — icon 32–512, app-icon 180–1024, favicon 16–64, lockup 680/1360.

## Правила
- **Dark-версію не став на світлий фон** (біле слово зникне) і навпаки — бери відповідний варіант.
- Clear-space: лишай навколо lockup вільне поле ≥ половини висоти знака.
- Мінімальний розмір wordmark — не менше ~90px завширшки; нижче бери `icon`/`favicon`.
- Не розтягуй, не міняй пропорції знак↔слово, не додавай тіні/градієнти/обведення, не перефарбовуй акцент.
- Шрифт wordmark у SVG — `Inter` з фолбеком на system-sans; якщо треба точний — підключіть Inter, або залиште фолбек (растр уже вшитий у PNG).

## Регенерація / нові розміри
PNG зроблені з SVG через `sharp` (Node). Будь-який новий розмір:
```bash
npx sharp -i svg/candor-icon.svg -o png/candor-icon-1024.png resize 1024
```
або з будь-якого SVG у векторному редакторі (Figma/Illustrator/Inkscape).

## Джерело
Знак і всі варіанти згенеровані з єдиного геометричного примітиву (діафрагма, gold `#C79A4E`) — усі lockup'и консистентні між собою.
